# pyTools

Инструменты для обработки данных маркетинговых исследований. Каждый набор лежит
в своей папке со своими зависимостями и документацией — общего кода между ними
нет, ставить всё сразу не требуется.

| папка | назначение |
|---|---|
| [SAV2Convert](SAV2Convert/) | конвертеры выгрузок SPSS: структура переменных для mtools, фиксированный ASCII, Excel |
| [HBCBC](HBCBC/) | Choice-Based Conjoint: генерация плана опроса и оценка индивидуальных полезностей методом иерархического байесовского анализа |

## SAV2Convert

`sav2adl.py` — читает метаданные `.sav` и выгружает структуру `.adl` со
справочниками `.smt` для системы mtools.

`pySmartSPSSExporter.py` — оконное приложение: выгружает `.sav` в фиксированный
ASCII с файлом разметки и в Excel, в том числе с заменой кодов на метки значений.

Подробности — в [SAV2Convert/README.md](SAV2Convert/README.md).

## HBCBC

`cbc_hb.py` — полный цикл CBC-исследования: генерация сбалансированного плана с
запретом на дублирование уровней, оценка индивидуальных полезностей на PyMC,
эффекты взаимодействия, None-концепт, режимы одиночного выбора и распределения
баллов, расчёт важности атрибутов по стандартам Sawtooth.

Подробности — в [HBCBC/README.md](HBCBC/README.md).
